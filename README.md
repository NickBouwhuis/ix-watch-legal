# ix.watch terms and privacy policy

The terms and the privacy policy of [ix.watch](https://ix.watch), as published at
[ix.watch/terms](https://ix.watch/terms) and [ix.watch/privacy](https://ix.watch/privacy),
each with a PDF/A download. The site is built from this repository.

- `terms.md`: the terms for the site, the API and its data, alerts, and running a sensor.
- `privacy.md`: what ix.watch collects and publishes, and for how long.

Each file's front matter holds its version and the date it takes effect. Every change is a
commit here, and every published version is a tag (`terms-1.0`, `privacy-1.0`, ...), so the
history shows exactly what changed between versions and when.

Questions: [noc@ix.watch](mailto:noc@ix.watch); about privacy: [privacy@ix.watch](mailto:privacy@ix.watch).
